# 교수별 대표 프로젝트 이미지 정리 폴더

이 폴더는 사용자가 직접 수집한 이미지 원본을 넣기 위한 작업용 폴더입니다.

## 사용 방법

각 교수/전문가 폴더 아래에 프로젝트별 폴더가 있습니다.

프로젝트 폴더 내부 구조:

- `originals/`: 수집한 원본 이미지를 그대로 넣습니다.
- `selected/`: 홈페이지에 실제 사용할 후보 이미지를 골라 넣습니다.
- `reference/`: 이미지 출처 캡처, URL 메모, 사용 허가 관련 자료를 넣습니다.

## 파일명 권장

가능하면 파일명은 아래처럼 정리합니다.

```text
01_main.jpg
02_sub.jpg
03_detail.jpg
source.txt
credit.txt
```

## 주의

- 웹에 바로 올릴 이미지는 `selected/`에 넣어주세요.
- 출처가 불명확한 이미지는 `reference/`에 URL이나 캡처를 같이 남겨주세요.
- 최종 홈페이지 반영 전에는 이미지 출처와 사용 가능 여부를 다시 확인해야 합니다.
